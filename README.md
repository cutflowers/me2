# 🐾 DOGGO — сайт про собак

Простой статический сайт про собак, готовый для публикации через GitHub Pages.

## Запуск локально

Просто открой `index.html` в браузере.

## Публикация на GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи `index.html`, `style.css` и `script.js`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Нажми **Save**.
6. Через некоторое время GitHub выдаст публичную ссылку на сайт.

## Возможности

- адаптивный дизайн;
- поиск по породам;
- случайные факты;
- переключатель тёмной темы;
- анимация главного экрана;
- работает без сервера и базы данных.
